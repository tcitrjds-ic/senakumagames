# senakumagames

YouTuber「せなくま」さん（[せなくまチャンネル](https://www.youtube.com/@senakumadesu)）を主人公とした2D・3Dファンゲームのプロジェクトです。

## ドキュメント

- **[GAME_PLAN.md](./GAME_PLAN.md)** — プロジェクト全体の大枠プラン（企画・素材パイプライン・技術スタック・ロードマップ）

## 成果物と進捗

1. **せなくまラン 🍟** — 2D横スクロールランナー（Phaser 3）… **プレイ可能** ✅
2. **せなくまとマンカラ 🥔** — せなくまと対戦するマンカラ（カラハ・ルール）… **プレイ可能** ✅
3. **せなくまアイランド 🏝️** — 3D箱庭探索ゲーム（Three.js + VRM）… 未着手
4. **Webポータル** — 各ゲームの入口となるページ（`portal/`）… **公開用に実装済み** ✅

## 開発の始め方

```bash
npm install
npm run dev            # せなくまラン の開発サーバー
npm run dev:mancala    # せなくまとマンカラ の開発サーバー
npm run build          # 両ゲームの本番ビルド（games/*/dist/）
```

## 操作方法

### せなくまラン

| やりたいこと | タッチ / マウス | キーボード |
|---|---|---|
| ジャンプ | 画面をタップ | スペース / ↑ / W |
| 高くジャンプ | 長押し（すぐ離すと低いジャンプ） | 押し続ける |
| 2段ジャンプ | 空中でもう一度タップ | 空中でもう一度押す |
| ポーズ / 再開 | 右上の ⏸ ボタン | P / Esc（再開はスペースでも可） |
| リトライ（リザルト画面） | 画面をタップ | スペース / Enter（Esc でタイトルへ） |

着地の直前に押したジャンプは着地と同時に出ます（先行入力）。別のタブやアプリに
切り替えると自動でポーズし、再開時は 3・2・1 のカウントダウンが入ります。
音量・全画面・ホームへ戻るボタンはポーズ画面の中にあります。
スマホを縦に持っているときは、ゲーム画面の外（上下の余白）をタップしてもジャンプできます。

### せなくまとマンカラ

| やりたいこと | タッチ / マウス | キーボード |
|---|---|---|
| くぼみを選ぶ（結果のプレビュー表示） | 触れる / マウスを乗せる | ← → / 数字 1〜6 |
| 決定 | 指を離す / クリック | Enter / スペース（数字キーは同じ数字をもう一度） |
| キャンセル | 押したままくぼみの外へずらして離す | — |

## テスト

```bash
npm test    # ジャンプ入力と障害物の出現間隔のロジックを検証（Node 22.18 以降）
```

ジャンプの手ざわり（高さ・先行入力の長さなど）は `games/runner-2d/src/constants.ts` の
`JUMP_TUNING`、障害物どうしの最低間隔は `games/runner-2d/src/spawn.ts` で調整できます。

## 公開（GitHub Pages）

`.github/workflows/deploy.yml` が、ポータル（`portal/`）と両ゲームを
まとめてGitHub Pagesへデプロイします。サイト構成は
`/`（ポータル）→ `/runner/`・`/mancala/`（各ゲーム）。

初回のみ設定が必要です:

1. リポジトリの **Settings → Pages → Source** を「**GitHub Actions**」にする
2. このブランチを `main` にマージする（以降は `main` へのpushで自動デプロイ）
   - すぐ試す場合は **Actions → Deploy to GitHub Pages → Run workflow** で
     このブランチを選んで手動実行もできます

公開URL: `https://<ユーザー名>.github.io/senakumagames/`

## キャラクター画像

| ゲーム | ファイル | 内容 | 作り方 |
|---|---|---|---|
| せなくまラン | `hero.png` + `hero.json` | 主人公のドット絵（正面顔・9コマ: 立ち/まばたき/走り4コマ/ジャンプ/落下/ミス） | `python3 tools/make_hero_sprite.py`（ビーズ作品 `assets/raw/senakuma_beads_reference.png` を見本に描き起こし） |
| せなくまラン・マンカラ | `face_cry.png` / `face_laugh.png` | 丸型カットイン（泣き顔・笑い顔） | TotK実況サムネから `tools/make_faces.py` |
| マンカラ | `player.png` / `player_jump.png` | せなくまのアバター（通常・ウインク） | サムネイルからの切り抜き（`tools/traced_masks.py` + `tools/cut_traced.py`） |

主人公のドット絵を直すときは `tools/make_hero_sprite.py` の文字グリッド（頭・胴・腕・脚の
パーツと、コマごとの組み合わせ）を編集して実行し直します。`--preview out.png` で全コマを
並べた確認用画像も出せます。

> キャラクター画像は権利者（せなくまさん）の許諾を得て使用します。素材を追加する際は
> `assets/raw/sources.txt` に出典を記録してください（詳細は GAME_PLAN.md セクション2参照）。
