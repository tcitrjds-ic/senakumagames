# assets/raw — 素材の記録置き場

## ここに置くもの

- `sources.txt` … 使った素材の「ファイル名・出典・取得日・許諾状況」の記録（必ず更新する）
- せなくまさん自身の作品の写真など、第三者の著作物が写っていない画像

## ここに置かないもの（リポジトリに入れない）

**実況のサムネイル原本（`thumb_*`）は入れません。** `.gitignore` で除外しています。

サムネイルには、せなくまさんの絵のほかに、実況しているゲームのロゴ・キャラクター・背景が
写っています。せなくまさんの許諾で使えるのは、せなくまさん自身の絵だけです。
このリポジトリは公開されているので、原本を置くとゲーム会社の画像まで配ることになります。

原本は手元のPCで保管し、切り抜き（`tools/cut_traced.py` / `tools/make_faces.py`）を行うときだけ
このフォルダに一時的に置いてください。リポジトリに入れるのは、せなくまさんだけを切り抜いた
結果（`assets/sprites/`）です。切り抜きのふちに背景の切れ端が残ったら
`tools/clean_cutout_edges.py` で落とします。
