# paintings — 美術館に飾る絵・題名・笑い声の置き場

ここに **スクリーンショット（絵）・音声（笑い声）** を置き、`manifest.json` に
ファイル名と題名を書くと、城内ホールの壁に自動で飾られます。コードの変更は不要です。

```
public/assets/paintings/
├── manifest.json   ← ここに一覧を書く
├── 01.png          ← 絵（png / jpg / webp）
├── 01.mp3          ← 笑い声（mp3 / ogg / m4a / wav）
├── 02.png
└── ...
```

## manifest.json の書き方

```json
{
  "paintings": [
    { "image": "01.png", "title": "ポテトを たべる せなくま", "laugh": "01.mp3" },
    { "image": "02.jpg", "title": "おどろく せなくま",          "laugh": "02.mp3" },
    { "image": "",       "title": "",                          "laugh": ""       }
  ]
}
```

| 項目 | 意味 |
|---|---|
| `image` | 絵のファイル名。空文字なら「じゅんびちゅう」の空きキャンバスになる |
| `title` | 2回目のタップで出る題名 |
| `laugh` | 3回目のタップで鳴る笑い声のファイル名。空なら効果音のみ |

- 書いた順に **No.1, No.2, …** と番号が付き、目立つ場所から順に掛かります
  （① 大階段の上・奥の壁 4枚 → ② 左右の壁 各2枚 → ③ 入口側の壁 下2枚・上2枚 → ④ 中2階の下 4枚）。
- 掛けられるのは **16枚まで**。17枚目以降は表示されません（増やしたい場合は相談してください）。
- 絵の縦横比は自由（額が絵に合わせて変わります）。目安は長辺 1280px 以下、1枚 500KB 以下。
- 音声はブラウザが再生できる形式なら何でも可。iPhone も考えると **mp3 か m4a** が無難。
- 一覧が空（すべて空文字）のときは 12 枚の空きキャンバスが並びます。

## 遊び方（タップの流れ）

1. 左半分のスティックで せなくまを歩かせ、絵に近づく（右半分をドラッグでカメラ回転、A でジャンプ）
2. 「みる」ボタン、または絵を直接タップ → 波紋が広がって絵が拡大
3. もう一度タップ → 題名（`title`）が表示
4. もう一度タップ → 笑い声（`laugh`）が再生
5. もう一度タップ（または右上の ✕）→ 閉じる

※ 権利者の許諾を得た素材のみ配置し、出典は `assets/raw/sources.txt` に記録すること。
