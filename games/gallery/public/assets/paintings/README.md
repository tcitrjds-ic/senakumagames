# paintings — 美術館に飾る絵・題名・笑い声の置き場

ここに **スクリーンショット（絵）・音声（笑い声）** を置き、`manifest.json` に
ファイル名と題名を書くと、ゲームが自動で額に飾ります。コードの変更は不要です。

```
public/assets/paintings/
├── manifest.json   ← ここに一覧を書く
├── 01.png          ← 絵（png / jpg / webp）
├── 01.mp3          ← 笑い声（mp3 / ogg / m4a / wav）
├── 02.png
└── ...
```

## manifest.json の書き方

```json
{
  "rooms": [
    {
      "name": "1F ひだりのへや",
      "paintings": [
        { "image": "01.png", "title": "ポテトを たべる せなくま", "laugh": "01.mp3" },
        { "image": "02.jpg", "title": "おどろく せなくま",          "laugh": "02.mp3" },
        { "image": "",       "title": "",                          "laugh": ""       }
      ]
    },
    { "name": "1F みぎのへや", "paintings": [ ... ] }
  ]
}
```

| 項目 | 意味 |
|---|---|
| `rooms[].name` | 部屋の名前。ホールの扉の上の看板に出る |
| `paintings[].image` | 絵のファイル名。空文字なら「じゅんびちゅう」の空きキャンバスになる |
| `paintings[].title` | 2回目のタップで出る題名 |
| `paintings[].laugh` | 3回目のタップで鳴る笑い声のファイル名。空なら効果音のみ |

- 1部屋に飾れるのは **3枚まで**。4枚以上書くと自動で「その2」の部屋に分かれます。
- 部屋は **1つの階に4部屋**（ホールの扉4つ）。5部屋目以降は大きな星の扉の先の **2F** に続きます。
- 部屋分けが面倒なら `{"paintings": [ {...}, {...} ]}` と1本のリストで書いてもOK（3枚ずつ自動で部屋分け）。
- 絵の縦横比は自由（額が絵に合わせて変わります）。目安は長辺 1280px 以下。
- 番号（No.）は manifest の記載順に自動で振られ、拡大時に「COURSE n」として表示されます。

## タップの流れ

1. 額をタップ → 波紋が広がって絵が拡大
2. もう一度タップ → 題名（`title`）が表示
3. もう一度タップ → 笑い声（`laugh`）が再生
4. もう一度タップ（または右上の ✕）→ 閉じる

※ 権利者の許諾を得た素材のみ配置し、出典は `assets/raw/sources.txt` に記録すること。
